### 3.5 判断是否有实质变化（避免空提交）

```bash
python -c "
import json,hashlib,subprocess
h=lambda x: hashlib.sha256(json.dumps(x,ensure_ascii=False,sort_keys=True).encode()).hexdigest()[:16]
new=json.load(open('data/_source.json',encoding='utf-8'))['items']
old=json.loads(subprocess.run(['git','show','HEAD:data/_source.json'],capture_output=True,text=True,encoding='utf-8').stdout)['items']
print('新:',len(new),h(new)); print('线上:',len(old),h(old))
print('结果:', '有实质变化，可提交' if h(new)!=h(old) else '无实质变化，仅时间戳')
"
```

## §4 提交与推送（带重试 + 脱敏 + remote 复位）

把下面整段复制执行即可（**推荐日常就用这段**）：

```bash
cd /d/帮老弟找工作项目
git add data/_source.json data/info.json
# 如改了脚本/计划，按需追加：
# git add tools/ assets/js/store.js plan-import.json 求职计划.md memory/

git commit -m "data: 简述本次变更，共N条(YYYY-MM-DD)" || { echo "无变更可提交"; exit 0; }

TOKEN=$(tr -d '[:space:]' < tools/.gh_token)
if [ -z "$TOKEN" ]; then echo "ERROR: token 为空，退出"; exit 1; fi
URL="https://${TOKEN}@github.com/zhuxingshifu1992/hefei-job-help.git"
LOG="/c/Users/YC1039/AppData/Local/Temp/push_err.log"

ok=0
for i in 1 2 3; do
  if git push "$URL" main 2>"$LOG"; then echo "PUSH_OK"; ok=1; break; fi
  echo "push 第 $i 次失败，5 秒后重试..."
  python - "$LOG" <<'PY'
import sys
tok=open("tools/.gh_token",encoding="utf-8").read().strip()
txt=open(sys.argv[1],encoding="utf-8",errors="replace").read()
print(txt.replace(tok,"***REDACTED***")[-600:])
PY
  sleep 5
done

git remote set-url origin https://github.com/zhuxingshifu1992/hefei-job-help.git
echo "RESULT=$ok"
```

**提交前安全检查（务必）**：

```bash
git status --porcelain | grep -iE "gh_token|token|secret" && echo "⚠️ 危险" || echo "✅ 安全"
```

## §5 部署验证

```bash
# 远端 SHA == 本地 HEAD？
TOKEN=$(tr -d '[:space:]' < tools/.gh_token)
git ls-remote "https://${TOKEN}@github.com/zhuxingshifu1992/hefei-job-help.git" main
git rev-parse HEAD

# 等 50 秒后验证线上数据
sleep 50
curl -s "https://zhuxingshifu1992.github.io/hefei-job-help/data/info.json" \
  | python -c "import sys,json;d=json.load(sys.stdin);print('线上条数:',len(d['items']),'| updatedAt:',d['updatedAt'])"

# 三个页面可达性
for p in index info plan; do
  printf "%-6s " "$p"
  curl -s -o /dev/null -w "%{http_code}\n" "https://zhuxingshifu1992.github.io/hefei-job-help/$p.html"
done

# 校验前端默认计划是否已部署（抓源码比对，比 WebFetch 可靠）
curl -s https://zhuxingshifu1992.github.io/hefei-job-help/assets/js/store.js | grep -oE 'id: "p[0-9]+"|start: "[0-9-]+"'
```

> 若 `curl -o /tmp/x` 报「no such file」，改用管道交给 python 解析（本机 `/tmp` 偶发不可写）。

## §8 安全审计

```bash
git grep -nIE "github_pat_[A-Za-z0-9_]+|ghp_[A-Za-z0-9]+" -- . && echo "⚠️ 含 token" || echo "✅ 无 token"
grep -rn "github_pat_\|ghp_" tools/*.py tools/*.bat tools/*.js 2>/dev/null && echo "⚠️ 硬编码" || echo "✅ 无硬编码"
git status --porcelain | grep -i gh_token && echo "⚠️ token 待提交" || echo "✅ token 未入库"
```

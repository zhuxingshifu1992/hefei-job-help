## 7. 最小可用环境（降级方案）

如果某些组件缺失，仍能完成核心运维：

| 缺失 | 影响 | 替代方案 |
|---|---|---|
| Python | 无法拉取/编辑/同步 | 手工编辑 `data/_source.json`（纯 JSON，可用记事本） |
| Node | 无法生成 `info.json` | 手工复制 `_source.json` 内容成 `info.json` 并补 `updatedAt`（仅限应急） |
| 腾讯文档连接器 | 无法拉取/写回 | 直接改本地 `_source.json`（它才是权威源），发布不受影响 |
| `gh` CLI | 无影响 | 用 PAT + HTTPS |

> 结论：**只要有 Git 和一个能编辑 JSON 的编辑器，就能维护这个项目。** 其余都是提效工具。

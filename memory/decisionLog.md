## 决定 1：资讯编辑责任从「用户手动改表」转为「AI 按指令改本地源 + 同步文档 + 发布」
- **决定**：资讯的编辑入口改为「AI 在对话中按用户指令改本地 `data/_source.json`，再 `sync_tdoc.py` 同步回腾讯文档 + 自动发布到 GitHub」。确立 `_source.json` 为单一可编辑源，腾讯文档降为镜像/备份。
- **原因**：用户希望减少自己的操作；AI 改本地文件比手改在线表格更可靠、可校验、可回退；保留腾讯文档作为人类可读的备份与查看入口。
- **被否决方案**：① 维持用户手动改表格（慢、易错、每次都要用户操作）；② AI 直接按 id 定点改单元格（实现复杂、易与整表覆盖冲突，且每次都依赖文档接口连通）。
- **时间**：2026-08-06（用户于对话中确认「我同意」实施方案）。
